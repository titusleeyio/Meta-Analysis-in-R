# Meta-Analysis in R
This repository contains reproducible R workflows for conducting Meta-Analyses in Public Health research. The workflow can be adopted for clinical research.

## Objectives
- Perform pairwise meta-analysis
- Generate forest plots
- Assess publication bias
- Conduct subgroup analyses
- Perform meta-regression
- Evaluate risk of bias (ROB2 and ROBINS-I)
- Produce publication-ready figures
